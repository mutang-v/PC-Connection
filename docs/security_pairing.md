# 安全配对试运行设计

- 配对入口：`POST /api/pair`，接收一次性 8 位配对码。
- 配对码：服务启动时随机生成，10 分钟失效，最多 5 次错误尝试，成功后不可重复使用。
- 客户端凭证：成功配对后生成高熵随机 Bearer Token；网页保存在该浏览器的 localStorage。
- 服务端凭证：仅将 SHA-256 摘要保存到 `data/device_token.json`，不保存原始令牌。
- 受保护接口：所有 `/api/*` 读取与操作接口都要求有效 Bearer Token，只有 `/api/pair` 例外。
- 撤销：停止服务并删除 `data/device_token.json` 后重启；旧令牌失效。
- 当前限制：HTTP 未加密；令牌可能被同一不可信网络上的流量观察者截获。因此只在可信私人热点/局域网使用，防火墙仅允许专用网络，禁止公网端口映射。后续正式版应采用 TLS、设备管理和更完善的密钥生命周期管理。
