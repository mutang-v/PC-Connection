电脑伴侣：模块化试运行版（安全配对版）

启动方式：
1. 双击 start_companion.bat。
2. 在电脑服务窗口查看“首次配对码”，8 位数字，10 分钟有效。
3. 手机和电脑连接同一个可信私人热点/局域网。
4. 手机打开 http://电脑的 WLAN IPv4 地址:8000，输入配对码。
5. 配对成功后，设备凭证保存在手机浏览器本地；电脑端只保存凭证的 SHA-256 摘要。

安全说明：
- /api/stats、/api/processes、/api/action 均要求 Bearer Token。
- 配对码 10 分钟有效，最多允许 5 次错误尝试，成功后即失效。
- 如需撤销已配对设备，先停止服务，再删除 data/device_token.json，然后重新启动并配对。旧设备上的令牌将失效。
- 当前服务仍使用 HTTP，局域网通信未加密；只在可信私人网络使用，Windows 防火墙仅允许专用网络，不要端口映射或暴露到公网。
- 本版本为单设备配对试运行版，不是经过专业安全审计的正式产品。

注意：首次运行后会在项目目录生成 data/device_token.json。请不要公开分享此目录或电脑服务窗口中的配对码。


本更新版新增“Windows 设置”固定动作；仍不支持任意命令执行，也不会自动更改系统设置。更新前请保留旧版本和备份。
